# Code of conduct

GeoLoupe follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, and focus on what is best for the
community and the science. Harassment and personal attacks are not accepted in issues, pull
requests, discussions or any other project space.

To report unacceptable behaviour, contact the maintainer privately (see the maintainer's GitHub
profile). Reports are handled confidentially.
