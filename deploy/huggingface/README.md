# GeoLoupe gallery

Open Earth data read live from public archives: hourly weather since 1940 (ERA5), Sentinel-2,
a 30 m elevation model, land cover, a climate model's ocean and weather stations, on one map with
the real values under the cursor. Code and documentation: https://github.com/salmanmohebi/geoloupe

The server opens its datasets when it starts (10–30 s); a map tile takes 0.3–1.5 s.
